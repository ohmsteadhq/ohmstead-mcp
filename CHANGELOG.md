# Changelog

## 0.1.2 (2026-11-14)

- The server now starts and lists its tools with no Ohmstead backend configured (a fresh machine, or a
  directory's inspector). Each tool call then says how to sign in.

## 0.1.1 (2026-11-12)

- Subsystem, component, page and position tools: `update_subsystem`, `remove_subsystem`, `update_components`,
  `remove_components`, `add_page`, `update_page`, `remove_page`, `set_block_positions`, `clear_block_positions`.

## 0.1.0 (2026-11-05)

- First release on npm (`npx -y ohmstead`) and the MCP Registry (`io.ohmstead/mcp`).
